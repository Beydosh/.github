# Beydosh PIM

Beydosh PIM ist eine Windows-Anwendung zur Produktdatenverwaltung. Damit kannst du Produktdaten importieren, im Katalog ordnen und pflegen sowie Verkaufsprofile vorbereiten. Die Anwendung ist in Entwicklung. Der Funktionsumfang hängt von der eingesetzten Version ab.
